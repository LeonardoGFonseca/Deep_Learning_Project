# 🧬 AMR Detection Pipeline: Klebsiella pneumoniae (Nanopore POD5)
### ⚠️ Target Strain: KP1779 Only

This repository contains a dedicated workflow for processing raw Nanopore sequencing data (POD5 format), converting it into nucleotide sequences, and identifying Antimicrobial Resistance (AMR) genes via BLAST+. 

**Note:** This current configuration is specifically optimized for the directory structure and naming conventions of strain **KP1779**.

## 🚀 Pipeline Structure

The process is divided into three sub-scripts to ensure modularity, simplify debugging, and optimize resource management on the server.

### 1. `01_setup_download.sh`
**Objective:** Environment preparation and data acquisition.
- Downloads and installs binary tools: **Dorado** (Basecaller) and **NanoBLAST**.
- Downloads the raw dataset for **KP1779** directly from the remote repository.
- Performs immediate cleanup of temporary files (`.tar.gz`) and failed read folders (`pod5_fail`) to optimize disk space.
- **Normalization:** Renames POD5 files to a sequential pattern (`KP1779_01.pod5`, `KP1779_02.pod5`, etc.) to ensure traceability.

### 2. `02_process_reads.sh`
**Objective:** Signal-to-sequence transformation.
- Utilizes the **Dorado Basecaller** (HAC - High Accuracy model).
- **Streaming Optimization:** The signal is converted from POD5 to FASTQ and immediately transformed into FASTA via `sed` in real-time. This prevents the creation of massive intermediate files, significantly saving storage space.
- **Output:** Individual `.fasta` files located in the `fasta_files` directory.

### 3. `03_run_analysis.sh`
**Objective:** Bioinformatics identification.
- Indexes the resistance gene database (`db_resitencia.fasta`) using `makeblastdb`.
- Executes **BLASTn**, comparing the sample reads against the resistance targets.
- Generates a final report in CSV format (`.csv`) containing alignment metrics (E-value, Identity, Alignment Length).
